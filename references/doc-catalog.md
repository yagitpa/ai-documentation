## Шапка документа

Каждый документ начинается так:

```markdown
# <Название документа>

| Поле | Значение |
|---|---|
| Назначение | <одна фраза> |
| Аудитория | <из каталога> |
| Статус | заполнен / черновик, пробелов: N |
| Обновлён | YYYY-MM-DD |
| Источники | `путь/к/файлу`, `...`, Q-003 |
```

## Единый источник

Каждый факт записан в одном документе, остальные ссылаются на него относительной ссылкой.

`N` — число меток `TODO (Q-NNN)` в документе. Слово `TODO` в поле статуса не используется, чтобы проверка не путала статус с меткой.

- Переменные и настройки описываются только в `04-configuration.md`.
- Схема хранилища данных описывается только в `02-architecture.md` → «Хранилище данных».
- Доступы описываются только в `05-access-map.md`.
- Метрики описываются только в `16-metrics.md`. В `01-overview.md` приводятся 1–3 главные метрики со ссылкой.
- Тексты промптов лежат только в `12-prompt-guide.md`. В `11-workflow.md` на них ставится ссылка по ID промпта.
